# CFCA-on-the-SNOW-V-Family
We provide the source code used for searching linear masks within the SNOW‑V family, covering both classical and conditional correlations.

# Experiments on reduced version of SNOW 5G
We have experimentally validated our claims on a reduced variant of SNOW 5G. Specifically, we completed an independence test for the sub-noise components N2 and N3, measured the practical conditional correlation values and compared them with the theoretical predictions, and carried out an initial‑state recovery of the LFSR using the CFCA, as described in Sections 3.2 and 3.3.
