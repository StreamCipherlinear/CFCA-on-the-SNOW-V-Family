# Conditional Linear Cryptanalysis of the SNOW-V Family

This repository contains the codes of the mask search and of the correlation computation presented in Section 4 (Applications to the SNOW-V Family) of our paper. The search is described in detail in the appendix, in the sections "Supplementary Material for the Search of Linear Masks in SNOW 5G" and "Supplementary Material for the Search of Linear Masks in SNOW-Vi".

The codes are organized as follows:

* The mask search for SNOW 5G, which yields the highest conditional correlation 2^-62.545 and the classical correlation 2^-66.626, is placed in the directory `CFCA on SNOW 5G`
* The mask search for SNOW-V and SNOW-Vi, which yields the highest conditional correlation 2^-42.999 and the classical correlation 2^-45.187, is placed in the directory `CFCA on SNOW-Vi (SNOW-V)`

Each directory contains its own ReadMe that describes the steps of the search, the files produced in every step and how to run the programs.
